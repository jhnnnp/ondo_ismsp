# UX Principles — 자가진단 + 질문기 레이어

> **상태:** 자가진단 루프 재정렬 (2026-07-29)  
> **프레임:** 제품 본체 = ISMS-P **자가진단**. 질문기는 이번 세션 우선 통제를 좁히는 레이어.  
> 관련: [`STRUCTURED_QUESTIONER.md`](STRUCTURED_QUESTIONER.md), `to do.md`

---

## 0. 상단 한 줄 (못 박기)

**카드에서 진단 상태(아직 모름/미이행/부분/이행)를 남긴다.**  
질문은 확인 각도이고, 「숙제 완료」가 아니다.  
이번 세션 우선 5–10개 ≠ 전체. 나머지는 **대기열**, KPI는 **전체 진행 응답완료 M / 적용 N**.

---

## 1. 루프

```text
1) 환경 맞춤
2) 이번 세션 우선 통제/질문을 좁힘   ← 질문기
3) 담당·화면·문서로 확인
4) 진단 상태를 남김                 ← 제품 본체 (assessments)
5) 갭/우선 목록이 다시 정렬됨
6) 대기열에서 다음 세션 이어가기
```

전부 보려면 여러 세션이 걸릴 수 있다. 숨기지 말고 진행률·대기열로 보여 준다.

---

## 2. 카드 CTA

| 한다 | 하지 않는다 |
|------|-------------|
| 아직 모름 / 미이행 / 부분 이행 / 이행 | 「이 질문을 확인함」(숙제 클리어) |
| 선택 → `assessments` + 재분석 | 신뢰도만 올리고 진단 불변 |
| 공식 문항은 접힌 근거 | 공식 문항 전부 체크 = 이행 |

---

## 3. 진행 표시 (필수)

- **전체 자가진단 진행** `M / N`
- **이번 세션 우선** `K개`
- **대기열** `W건` (우선 카드 밖, 미점검·미이행·부분)

---

## 4. 성공 판정

1. 사용자가 “지금은 이 몇 개만 진단하고, 나머지는 대기”를 이해하는가  
2. 진단 버튼을 누르면 전체 진행 M/N이 바뀌는가  
3. 숙제 완료처럼 읽히지 않는가
