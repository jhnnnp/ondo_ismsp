# 프로젝트 개선 구현 점검 (2026-08-11)

## 결론

기존 자가진단 구조 개선과 국가법령정보 연동의 **기반 기능은 구현**되어 있다. 다만 법령해석 실데이터 수집, 조문 본문·개정 이력, 관리자 검토, 일부 공식 KB 품질 정리는 아직 완료되지 않았다. 따라서 전체 개선 계획을 완료로 볼 수는 없다.

## 완료

- 진단 상태 중심의 자가진단 흐름(모름·미이행·부분 이행·이행)
- 전체 진행 M/N, 우선 통제, 다음 미완료 통제 이동
- 공식 안내서 요구사항·확인사항·증적을 통제 상세에 표시
- 규칙 기반 갭·인과·복합 위험·확인 목록·보고서
- 법령해석 목록/상세 XML 파서와 정규화 모델
- 화면 요청과 분리된 배치 동기화 스크립트
- 로컬 법령해석 저장소와 검색 API
- 통제별 법령·조문 자동 매핑 및 관련도 점수
- 법령 API 키의 서버 전용 환경변수 처리
- 허용 도메인, HTTPS, XML 크기·DOCTYPE/ENTITY 차단
- 통제 상세 카드의 법적 근거 영역
- 통제 요구사항, 조문명, 현행 법령 원문 링크, 실무 점검 질문, 증적, 안내서 출처 표시
- 법령해석 동기화 미설정 상태 표시
- 잘린 OCR 결함 사례의 화면 노출 방지

## 미구현 또는 후순위

- 법령해석 자동 매핑 후보의 관리자 승인·거절 화면
- 개인정보보호위원회 의결문, 분쟁조정례, 판례 등 출처 확장
- 대규모 데이터용 SQLite FTS5 또는 PostgreSQL 검색
- executive report SSE
- 증적 GRC 및 사례집 인용 RAG 고도화
- 저결함 통제의 질문 수작업 보강
- 결함 동시발생 행렬 등 Phase 3 분석

## 현재 외부 연동 상태

- `DATA_GO_KR_SERVICE_KEY`: 설정되지 않음
- 법령해석 동기화 상태: `NOT_CONFIGURED`
- 따라서 현재 화면에는 통제별 공식 안내서 근거와 관련 조문은 표시되지만, 법제처 법령해석례의 질의요지·회답·이유는 아직 표시되지 않는다.

## 검증 결과

- 법령 관련 집중 테스트: 10개 통과
- `GET /health`: 정상
- `GET /controls/3.3.1/legal-basis`: 정상
- 브라우저 확인: 요구사항, 조문명, 공식 원문 링크, 실무 점검 질문, 증적, 동기화 상태가 실제 상세 카드에 표시됨
- 전체 프런트 테스트의 기존 실패 3건: 변경된 UI 문구 2건과 제거된 CSS 선택자 1건에 대한 오래된 계약 테스트
